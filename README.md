# Zunmera

### You're on the roof. Zunmera handles the lead.

Zunmera is an AI-enabled lead recovery and appointment booking prototype designed for roofing contractors.

It helps move an incoming homeowner enquiry through **conversation → qualification → availability → booking**, while keeping critical actions under backend control and allowing the contractor to step in when needed.

> **Status:** Working prototype built and tested with synthetic lead data.

📄 **[View the full Zunmera Product Case Study](./Zunmera_Case_Study.pdf)**

---

## What It Does

- Captures incoming contractor leads
- Starts a persistent homeowner conversation
- Collects qualification details such as the roofing problem, address, urgency and preferred timing
- Presents valid appointment availability
- Validates appointment selection server-side before booking
- Tracks leads and booked outcomes in a contractor dashboard
- Supports contractor takeover and human escalation
- Handles follow-up and reminder workflows

---

## Workflow

**Enquiry → Conversation → Qualification → Availability → Booking → Contractor Dashboard**

The conversational layer assists the homeowner, while backend rules retain control of qualification state, escalation, availability and booking.

---

## Tech Stack

**Backend:** Python, Flask  
**Frontend:** HTML, CSS, JavaScript  
**Data:** SQLite / Turso  
**Deployment:** Vercel  
**Development:** Git & GitHub, AI-assisted development

The prototype also includes automated regression testing, server-side booking validation, bounded conversation context and safeguards around AI-provider output.
